# Research Grid｜研究网格

## 一句话定义

用低对比网格建立推演空间，以强结论控制注意，再用一个“输入—判断—结果”机制把复杂问题变成可理解的答案。

## 适用场景

- 观点海报、课程封面和知识卡片；
- 咨询判断、案例结论和研究发布；
- 需要表达筛选、验证、转化或闭环的视觉物料。

它不适合堆满长流程、十几项福利或复杂详情。信息超载时拆成系列。

## 视觉人格

- 冷静、精确、有实验气质；
- 像研究工作页，不像 SaaS 控制台；
- 秩序明确，但只有一个节点接管注意；
- 数字感来自坐标和关系，不来自赛博渐变。

## 默认颜色角色

色值可以被个人配置覆盖，角色关系保持稳定：

| 角色 | 默认值 | 用途 |
|---|---|---|
| 主空间 | `#FCFEFF` | 白色主体 |
| 标题 | `#111A22` | 核心判断 |
| 主蓝 | `#087CB8` | 关键词、机制边界和行动 |
| 天空蓝 | `#8FD3FF` | 浅底与辅助关系 |
| 冷灰 | `#536B77` | 次级说明 |
| 线框 | `#AAC4D0` | 坐标和分隔 |
| 信号色 | `#FF5B40` | 唯一验证点，通常只出现一次 |

蓝色不是通栏背景，不使用大面积黑块。

## 网格

```css
.poster {
  background:
    linear-gradient(rgba(107,158,181,.11) 1px, transparent 1px),
    linear-gradient(90deg, rgba(107,158,181,.11) 1px, transparent 1px),
    #fcfeff;
  background-size: 32px 32px;
}
```

网格是坐标系，不是装饰纹理；必须低对比，不能压过文字。

## 五段骨架

1. **身份眉头**：品牌／人物和日期／版本，用细线结束。
2. **强结论区**：近黑重体为主，只给一个词或短语主蓝强调。
3. **单一机制区**：默认使用“原始输入 → 核心判断 → 被验证结果”。
4. **中文结果句**：把机制翻译成读者能理解的价值。
5. **三联结果与行动页脚**：最多三个收益／阶段，加真实行动入口。

中文负责理解，英文只做索引。手机海报中用户必须阅读的中文不小于 18px。

## 禁止项

- 为了证据感伪造编号、数据和客户材料；
- 通栏蓝条、霓虹渐变、机器人、芯片大脑和无意义 3D 球；
- 把网页按钮、导航和卡片直接搬到海报；
- 一页同时使用多套图形机制；
- 用假二维码冒充可发布版本。

## 验收

1. 缩成手机缩略图，核心判断是否仍可读？
2. 机制图是否只解释一条关系？
3. 任一装饰删除后不损害理解，就删除。
4. 信号色是否只有一个明确语义？
5. 画面像研究判断，还是套了网格皮肤的网页？
