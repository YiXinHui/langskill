# 证据与输出规范

执行理论根脉研究或来源核验时完整读取本文件。

## 一、证据等级

按以下顺序寻找和引用：

1. 原著、原始论文、正式标准、法律或机构档案；
2. 作者或机构的权威版本、大学与专业学会资料；
3. 同行评议论文、学术百科和可靠研究专著；
4. 高质量二手解释；
5. 普通网页、媒体文章和个人解读，只作线索，不承担关键历史结论。

关键主张就近附来源。无法访问一手材料时说明证据降级；不同来源冲突时呈现冲突，不替用户暗中裁决。

“最早出现”“首次提出”“首创”需要更严格的证据链：

1. 先定位现存原始文本、权威校勘本、正式档案或同时代记录；
2. 再用可靠研究说明成书、刊刻、编纂和年代争议；
3. 后出的年谱、回忆和二手文章只能证明它们记载了什么，不能自动证明事件发生时已经有同名原文；
4. 证据只能支持“现存最早可定位记录”时，就使用这一准确表述，不升级成绝对首创。

## 二、节点证据卡

每个进入主脉络的节点至少回答：

| 字段 | 要求 |
|---|---|
| 名称 | 中文与原文名称；后人命名需注明 |
| 原义 | 在原始语境中解决什么问题 |
| 时间与主体 | 人物、机构、年代；不确定则标注 |
| 关系类型 | 直接祖先 / 形式化地基 / 治理原则 / 平行类比 / 后代工具 / 当代综合 |
| 贡献 | 能解释当前对象的哪一部分 |
| 边界 | 不能解释什么，是否存在时代或场景限制 |
| 证据 | 原始或权威来源链接 |

只有当来源能支持“继承、提出、首创”等历史关系时，才使用这些词。仅有结构相似时写“可对照”或“平行类比”。

## 三、轻量概念链

适用于一条实践经验或一个边界清楚的概念：

```markdown
## 用户经验

「用户原话」

## 正式名称

**概念中文名（English Name）**：一句大白话定义。

- 重合：...
- 差异：...

## 主脉络

[根层理论] → [中层原则] → [直接概念] → [用户经验]

每个箭头标注“属于、形式化、直接继承或本次映射”。

## 相邻概念与边界

...

## 一句话

[它在知识谱系中的准确位置，以及对当前实践的意义]
```

如果多个候选都只部分匹配，不让用户凭空选择；先说明不同候选分别解释哪一部分，再指出当前最稳妥的命名。

用户要求简短时，仍按“名称与定义—关键差异—相邻或上位关系”交付三个最小部件，每项一句即可。这样既避免长报告，也防止把口语经验与正式概念草率等同。

## 四、复合对象的多根脉

适用于知识体系、组织机制、复杂方法论和跨文化母题：

```markdown
## 现实入口

[谁在什么处境下会遇到什么代价；为什么值得追]

## 先把几个词分开

| 词 | 本次含义 | 不等于什么 |

## 根问题

1. ...
2. ...
3. ...

## 多条根脉

### 根脉一：[它回答的问题]

[历史节点与关系类型] → [形式化发展] → [现代落点]

### 根脉二：...

## 本次综合

[用一句主张或一个关系式，说明这些根脉怎样共同构成当前对象]

## 回到用户的问题

[哪些认识成立，哪些需要调整，下一步如何行动]

## 边界与争议

- 历史争议：...
- 理论解释不到的地方：...
- 常被误当成源头的后代工具：...
```

## 五、跨文化溯源

跨文化分析追求功能互补和证据准确，不追求数量对称。

- 分别恢复概念在自身传统中的原义，避免用现代西方术语直接套译东方文本，也避免把相似句子宣布为同一理论。
- 区分存在论或认识论地基、形式化模型、命名与辨实、实践与验证、节制与演化等不同贡献。
- 最后的综合属于当代重构时必须明说，不能冒充某部经典的原始结构。

## 六、质量自检

- 开头是否让目标读者知道这件事与自己有什么关系；
- 是否先分清重名或近义概念；
- 复杂对象是否拆成必要而不重复的根问题；
- 每条关系是否区分历史继承、理论奠基、类比和后代实现；
- 关键事实是否有足以支撑该强度主张的来源；
- 是否把根脉重新合成为当前可用的判断；
- 是否说明边界、争议和不能从来源推出的内容；
- 完整研究是否给出可证伪判断及其失效条件；
- 来源核验中的“最早”是否由原始或权威版本承担，而非只靠二手文章；
- 简单问题是否仍然简洁，没有被多根脉框架做重。
