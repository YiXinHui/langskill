# 学员知识萃取初始化轻量回归

日期：2026-08-23

## 执行方式

- 用 `codex exec --ephemeral --ignore-rules -s read-only` 读取当前 Skill 与任务所需 references。
- 只验证对话行为，不写配置、不创建外部载体、不接触生产数据。
- Codex CLI 期间 WebSocket 多次断开，自动降级 HTTPS 后三条用例均完成；该网络告警不影响最终文本判定。

## 结果

### 1. 单人 Excel 首次初始化

通过。回复默认只启用概念库与判断库、私有、先预览后确认；没有把四库、分类树或自动化抛给用户，只继续询问工作簿位置。

### 2. 团队钉钉且没有连接器

通过。回复明确标为 `needs_setup`，没有声称已创建或已连接钉钉；保持 starter 两库，要求确定审核人与目标文档，不自动扩大团队权限。

### 3. 连续聊天截图含重复与缺上文

通过。回复承诺按重叠消息去重，把最后一张标为上文缺失，并阻止依赖缺失上下文的内容成为完整判断；在没有实际图片时请求上传，不伪造萃取结果。
