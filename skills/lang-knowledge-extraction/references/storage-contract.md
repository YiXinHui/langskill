# 载体与写入契约

载体选择解决的是维护成本和协作能力，不改变概念、判断、案例与金句的语义标准。每个配置只能声明一个当前权威源；备份和导出不能同时冒充权威。

## 先按能力分型

| `storage.mode` | 常见载体示例 | 适合情况 | 主要限制 |
|---|---|---|---|
| `structured_table` | 飞书多维表、其他在线结构化表 | 多人协作、状态筛选、关系字段、自动化 | 需要连接器、权限和稳定对象 ID |
| `workbook` | 本地 Excel、WPS 工作簿、在线表格 | 单人或小团队、容易导入导出 | 关联和并发较弱，需文件备份 |
| `document_table` | 钉钉／企微／其他在线文档中的表格 | 团队已有文档习惯、量小 | 结构校验、去重、并发和关联能力较弱 |
| `database` | 用户自有数据库或 API | 已有技术维护、查询和集成需求 | 必须有 schema、鉴权、备份和恢复能力 |

平台名称只是适配信息。运行时先检测当前宿主实际拥有的连接器或文件能力；没有相应工具时生成可导入模板和配置草稿，返回 `needs_setup`，不能假装已经连接。

## 统一逻辑角色

配置使用固定逻辑角色：

```text
concepts, judgments, cases, quotes
```

只有启用的角色必须有物理映射。物理对象可以是表 ID、工作表名、文档区块锚点、数据库表或 API resource。逻辑角色不能靠相似显示名猜测；已有对象无稳定 ID 时，保存文件路径＋工作表名或文档 URL＋区块锚点。

## 各载体的最小实现

### 结构化在线表

- 每库一张逻辑表；starter 只需概念表与判断表。
- 优先使用平台真实记录 ID；跨库关联只写回读后的真实 ID。
- 每次写入前读取实时字段、类型和权限；字段缺失先 dry-run，不自动批量改表。
- 分享、成员、角色和高级权限变更需要明确确认。

### 工作簿

- 一个工作簿，一个库一张工作表；starter 使用 `concepts`、`judgments`。
- 使用 UTF-8 文本、ISO 日期和稳定 ID；关联字段保存逗号分隔 ID，不保存易变行号。
- 写入前检查文件是否被移动、锁定或有未保存修改。无法安全并发时停止写入。
- 初始化可直接复制 [../assets/knowledge-extraction-starter.xlsx](../assets/knowledge-extraction-starter.xlsx)，也可导入 [../assets/starter-concepts.csv](../assets/starter-concepts.csv) 与 [../assets/starter-judgments.csv](../assets/starter-judgments.csv)。需要重新生成工作簿且当前 Python 环境已有 `openpyxl` 时，运行 `scripts/create_starter_workbook.py <输出路径>`。
- 备份位置与频率必须写进配置；Skill 不擅自覆盖同名文件。

### 在线文档表格

- 每个库使用独立且可定位的表格区块，保存区块锚点。
- 不支持关系字段时使用稳定 ID 文本引用。
- 多人同时编辑或记录量增大后，优先迁移到结构化表；迁移前保持旧文档只读，避免双写。

### 自有数据库／API

- 配置只保存 endpoint／schema 名称和凭证引用，不保存秘密。
- 写入必须具备唯一键、幂等 upsert 或明确的 create/update 契约。
- 声称可用前验证 schema、最小权限、超时／错误、备份和恢复路径。
- 未经用户授权不创建生产表、不执行迁移、不改访问权限。

## 字段映射

逻辑字段以 `library-contracts.md` 为唯一语义源。配置可提供物理字段别名，但别名只做名称映射，不改变字段含义。发现用户现有表字段更多时保留，不顺手删改；发现同义字段时先给合并建议。

## 写入与回读

每条写入至少执行：

1. 在当前权威源查稳定写入键和语义重复；
2. 确认目标逻辑角色已启用；
3. 按状态和可见范围写入；
4. 回读真实 ID／位置、核心文本、状态、来源和关联；
5. 回读不一致时报告失败，不重试成重复记录。

`preview_then_confirm` 的预览不是第二套存储；只存在当前对话或用户明确的临时草稿中。`preview_only` 不建立隐藏积压。

## 换载体与迁移

换平台时先生成只读盘点、字段映射、重复处理、附件／来源保留、权限和回滚方案。明确切换时间后，旧载体改为只读历史或归档；在新载体完成数量、抽样内容、状态、来源和关联回读之前，不宣布迁移完成。
