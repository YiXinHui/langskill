# 滴答清单

用官方 `@suibiji/dida-cli` 操作国内版滴答清单，交付实际查询结果或已核验的变更。
只承担滴答数据操作与证据整理；个人目标、业务复盘的判断和写入交回调用方。

## 执行流程

1. 识别查询、复盘取证或写入意图、对象和周期；已有上下文先查询，只问找不到或会改变结果的缺口。
2. 初次使用、安装或授权异常时，读取并执行 [连接与命令](references/cli.md) 的连接分支。以 `dida project list --json` 成功读取真实清单为连接验收；国际版 TickTick 结果不能替代国内账号。
3. 查询当前待办：先列现网清单，按名称匹配唯一 ID，再读对应清单或搜索任务。查看 TODO 时展开 `items`，分别显示父任务和检查事项状态；命令见同一参考文件的查询分支。
4. 为日／周／月复盘读取结果：先执行下方脚本，再按需要读取未完成任务、习惯、专注及具体任务。必读 [取证规则](references/evidence.md)，交付事实、来源、覆盖窗口和缺口。
5. 创建、修改、完成、移动或删除：读取 [连接与命令](references/cli.md) 的写入分支，核对用户已经授权的动作、唯一对象和受影响范围；执行后用查询命令回读。已明确授权的范围无需重复确认。

## 复盘查询

在本 Skill 根目录执行，日期均为包含当天的本地日期：

```bash
python3 scripts/review_snapshot.py --from 2026-09-01 --to 2026-09-30
```

默认从滴答偏好读取时区；需要覆盖时加 `--timezone Asia/Taipei`。
脚本按最多10个本地日分段调用官方 CLI、按任务 ID 去重并核对完成时间；JSON 不输出正文，疑似凭据标题整体遮蔽。
返回的是已查询窗口中的完成标记和检查事项，不能证明业务成果或覆盖未返回的数据。
某段查询或数据解析失败则整体失败，不把部分数据写成完整成功；无结果也如实显示。

## 认证与隐私

本 Skill 不直接接 API、不自行读取或保存 token；认证完全由官方 CLI 的 `dida auth login` 管理。
保留已有效的官方登录，禁止复制凭据进 Skill、提示词、命令参数、公开仓或日志；不生成第二份凭据文件。
`dida auth status` 会显示 token 片段，认证检查使用实际只读查询；不得原样输出其结果。
任务标题也可能含凭据。直接查询的原始输出先在本地筛选脱敏，禁止整份原样回显。
不默认长期保存任务镜像，不自动同步、加提醒、改权限或分享数据。

## 完成标准

- 查询匹配真实账号、清单和周期，保留来源 ID、完成时间、父子状态及覆盖限制。
- 任务标记、实际结果、推断与建议分开；未勾选不自动判定未执行。
- 写入已读回核验，部分失败明确报告；未授权的动作不执行。
- 汇报用户可读结果及可打开的网页入口，敏感内容不回显。
