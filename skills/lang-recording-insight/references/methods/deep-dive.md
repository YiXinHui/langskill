# 深挖选中项

对用户选中的每一条依次完成：

1. **原话证据**：上下文、说话人、位置，区分原话与转述。
2. **命题提纯**：把候选改写成可判断的清晰命题。
3. **逻辑链**：前提如何导向结论，中间是否跳步。
4. **支撑与反证**：现有证据、缺失证据、最强反例。
5. **适用边界**：对谁、在什么条件下成立。
6. **信度评级**：事实可靠性和推理可靠性分开判断。
7. **下一步用途**：研究、试验、内容、产品或行动；只建议，不擅自写入外部系统。

深挖输出必须区分三层：

```text
录音里明确说了什么
→ 可以合理推断什么
→ 仍需验证什么
```

深挖是给用户看的分析，不是知识库成稿。用户之后要把这条写进知识库，按 [勾选落地](pool-review-and-landing.md) 写，不把上面七步当成稿的栏目。
