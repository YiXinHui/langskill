# 会议自动交接回归

按 Skill 与宿主集成检查以下输入和可观察结果；仅语句检查不能替代线上执行回执。

| 场景 | 预期 |
|---|---|
| 已有长期授权，复盘发现两场尚未整理的会议 | 实际投递获准 CEO 入口，绑定真实接单；逐场交回纪要、台账、原行动及跟进，不能只列候选 |
| 次日复盘再次发现同一录音，标题已改、原 AI 仍执行中 | 按来源 ID 复用任务和回执，不新建纪要、AI 待办或滴答 |
| 无新私聊，但队列有一场纪要已出、行动未核验的会议 | 继续原任务验收；资产与行动分别记录，不提前全部完成 |
| 纪要已回读，滴答同步或台账关联失败 | 保留已完成证据，仅续失败步骤，汇报部分完成 |
| 新用户只有定时配置，没有长期或当次授权 | 只读候选和具体缺口；不投递写入指令，不写公司记录 |
| 会议有未定负责人或日期，含合伙人敏感议题 | 不猜负责人／日期、不排今日任务，沿原权限与通知门禁 |
| 当日只确认其中一项行动，原公司滴答已存在 | 个人只新增该项原记录引用，沿用 ID，刷新状态；不再推公司任务 |
| 两个进程分别记录会议交接和私聊回执 | 锁内重读合并后两类回执均保留，未知字段不丢失 |
