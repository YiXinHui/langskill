# 初始化项目

在本机没有 `references/personal-config.md` 时执行。目标是为当前用户找到或建好唯一的个人目标项目，并写出本机配置。

## 1. 先找

- 用 `lark-cli drive +search` 搜标题含「个人目标总控」的文档，用 `lark-cli base +title-resolve` 搜「个人目标执行台」。
- 找到唯一的一套：读总控文档和执行台，按字段合同核对字段，然后跳到第 3 步。
- 找到多套，或只有其中一个：列出候选给用户选，不新建。

## 2. 再建（用户确认要建、并给出放在哪个文件夹之后）

1. 在用户指定的位置建项目文件夹「个人目标管理」；用户没给位置，就问一句，不在云盘根目录猜着建。
2. 建「01｜个人目标执行台」Base：按字段合同的顺序建六张表，先建没有关联的字段，再加双向关联字段，最后加公式字段和视图。每张表建完都用 `+field-list` 回读。
3. 建「00｜个人目标总控」文档，包含：用途（只在执行台维护）、入口表（执行台链接、其他相关文档）、节奏与规则（333、日／周／月复盘）、执行台的视图说明、还没做、变更记录。不预填用户的目标。
4. 年度目标表只建空表；当年的维度和目标在第一次「做年度目标」时，由用户逐项给出。

## 3. 写本机配置

按 [public-config-example.md](public-config-example.md) 的格式，写出 `references/personal-config.md`：总控文档、执行台、项目文件夹的链接，各表的 table_id，时区，周起始日（默认周一）。这个文件只留在本机，不进仓库，也不贴进对话以外的地方。

## 验收

项目文件夹里只有一份总控文档和一个执行台；六张表的字段与字段合同一致；用一条测试记录验证四个公式，验证完删掉这条测试记录；本机配置能读通。
