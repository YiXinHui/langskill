## 归属与晋升

原始材料 → 工作中的卡片 → 成熟知识单元 → 经实践验证的方法论 → 金句/故事结晶。
这是成熟度关系，不是每份材料都必须经过所有文件夹。先判断是谁的、是什么，再判断是否达到目标层的门槛，不凭 AI 自动生成就升级。

| 输入 | 落点与门槛 |
|---|---|
| 别人的课、文、视频或方法原件 | `08-他山之石/<来源>/`；先确认作者/博主/机构/栏目，不按领域建默认大篮子，不发明来源 |
| 自己学习别人理论并推演的笔记 | 实体放他山之石的来源目录，可在卡片笔记放相对链接；不复制两份正文 |
| AI 调研、对比、过程稿、随想、未成熟判断 | `01-卡片笔记/`，明确草稿和证据边界 |
| 自己的 SOP、小教程、可复用操作说明 | `06-工具箱/`；业务实例放公司目录 |
| 本人打磨确认、独立可读的原子问题/观点/概念 | `02-知识单元/` 对应类型；不能只有索引链接，不能把别人的观点冒充自己的 |
| 经实践验证的闭环体系 | `03-方法论/`；仅理解他人理论或 AI 写成框架不满足门槛 |
| 核实来源和表述的金句、故事 | `04-金句库/`、`05-故事库/`；保留真实出处，不改变说话人归属 |
| 完整录音分析 | `07-录音分析/`，是参考级原矿；只增不改，纠错另存并回链 |

晋升由本人判断。既有明确授权可用于形成待审候选，不自动视为确认或直接进入成品层。公司复用个人/外部资料时用参考说明或来源链接，不复制成另一份权威原件。

## 命名与维护

- 知识单元：`主题.md`，不加领域标签；问题用问句命名，分类由问题/观点/概念子目录承担。
- 主题推演：`主题_YYMMDD.md`；学习笔记：`主题_交互学习.md`；随想可按内容命名。
- 录音分析：`YYMMDD_主题.md`；金句和故事按日期或来源命名。
- 主题推演稿达到 15 篇或超过 30 天未推进时，列出待检查清单，由本人决定晋升、继续保留或废弃；不自动删除。随想、长期学习笔记和链接入口不算入该阈值。
- 维护 `02-知识单元/索引.md`。修改目录职责或晋升规则时按总索引的治理变更规则记录。

## 写作前检索顺序

知识单元 → 录音分析 → 金句库 → 他山之石中已有的文稿原件 → 已有选题 → 已验证的内容规律。先找到证据与可复用内容，再决定是否新写；索引对应云端时先查云端当前版本。

涉及原料区前必须先读 [原料隔离协议](../10-原料-flomo-慎用/.docs/README.md)。原料不进入上面的默认检索路径。
