# 统一研究入口替代演变—结构研究

## 给使用者的一句话

公开研究能力统一为 `/lang-research`：用户只需说明想搞懂什么，Skill 会自行决定做理论溯源、历史演变、当前结构或完整交汇研究。

## 为什么改

旧 `/lang-evolution-structure` 与私人环境中的“溯源”承担的是同一条研究链的不同片段，迫使用户先判断该调用哪套方法。旧版还固定要求追溯三十年以上、分三段等待确认并写入私人目录，导致简单问题被做重，也不适合作为公开通用能力。

这次反馈属于 L3：问题来自可迁移的研究编排逻辑，而不是某个题目的措辞或个人配置。

## 做了什么

- 新增 `lang-research`，统一根脉、演变、结构和交汇四个研究维度。
- 按真实问题自动选择轻量、定向或完整深度，默认连续推进。
- 分开“理论根脉”和“具体对象演变”，并要求交汇产生新增、可证伪的判断。
- 删除固定年代、固定长度、固定停顿和私人目录写入要求。
- 把证据、跨文化研究、演变结构和输出规则放入两个 references。
- 加入原始失败、相邻复杂场景、轻量反例和来源核验例外四类回归。
- 从目录、机器清单和 README 下架 `lang-evolution-structure`；旧英文名和中文名通过 `skill-renames.json` 迁移到 `lang-research`。

## 公共与私人边界

公开核心只保留跨个人、跨组织成立的研究方法。私人目录、知识资产落点、内部 Skill 名称和业务配置没有进入公开仓；需要保存、发布或转化产物时，由安装环境中的相应能力接管。
