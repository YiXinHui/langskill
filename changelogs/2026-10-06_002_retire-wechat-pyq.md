# LangSkill v0.22.0：退役专属朋友圈日更规划

（2026-09-27 起草，原定 v0.19.0；期间 v0.20.0、v0.21.0 先行发布，本次随 v0.22.0 提交。）

`lang-wechat-pyq` 必须依赖使用者另备的个人框架和素材目录，公开包无法独立完成首次使用。本版从公开 Skill 清单移除该入口；`lang-wechat-writing` 继续承担有来源的单条朋友圈草稿，不再指向已退役工具。

`skill-renames.json` 用 `null` 标记退役名称，升级时只在确认旧入口属于本仓安装并完成备份后清理，来源不明或内容不同的同名入口保留并报告冲突。同时删除未被入口引用的 `lang-skill-iteration/references/generic-cases.md`。

2026-09-27 起草时本地验证：15 个公开 Skill 的目录和清单一致；Codex、Claude Code 与 CodeBuddy 的全新安装发现检查、版本检查、敏感信息预检均通过。已有安装的退役入口清理逻辑尚未在三端真实旧安装环境完整演练。
