# LangSkill v0.23.0：lang-goals 1.4.0 每日待办推送滴答

- 每日待办经本人确认写入后推到滴答：按所属月目标的「滴答清单」字段进对应清单，不进收集箱；挂在 🐸 目标下的待办标题带「🐸」并设高优先级；任务 ID 回填执行台。
- 子任务：能拆才拆，每层最多 3 个、最多两层（第二层建成滴答子任务）；超出时脚本报错、不写入；滴答里已有的检查事项不覆盖。
- 状态只在滴答里操作：收口时按任务 ID 回读完成、放弃、延期，经本人确认后才改执行台；Agent 不在滴答里勾选、放弃或删除。
- 先后顺序年→月→周→日；约人见面、单场讲课这类一次性的事可直接挂月目标，不占周名额。
- 字段改名：「月成果」→「月目标」，「周结果」→「周目标」。
- 新增 `scripts/dida_sync.py`（调用官方 dida CLI，push／read 两种模式，防重复推送）；回归覆盖收集箱误推、重复推送、延期不被覆盖、删除与移动识别、子任务上限和改名。
